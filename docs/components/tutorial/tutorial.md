# NDMVR-Core Tutorial

Welcome to the NDMVR-Core tutorial! This guide will walk you through using Three.js with our class components,
helping you understand and utilize the full potential of the NDMVR-Core visualization library.

## What We'll Cover

Throughout this tutorial, we'll explore:

- Visualization Components
  - Histogram rendering
  - JSROOT integration
  - Canvas setup and management
  - Raycasting and interaction handling
  - THnPainter functionality

- Component Communication
  - RxJS-based message passing
  - State management
  - Configuration handling
  - Event dispatching

- Advanced Features
  - Extending components with custom functions
  - Creating custom visualizations
  - Integration with existing Three.js projects

Each section will include practical examples and detailed explanations to help you master the NDMVR library's features
and capabilities.

## Ways to get started
It is possible to get started using multiple ways.

### Gitlab pages
For the quickest preview, you can use our [gitlab pages](https://ndmspc.gitlab.io/ndmvr-core/).

### Copy repository
- If you wish to play around with the demo code on our Gitlab pages, or change the components itself, you can clone the [repository](https://gitlab.com/ndmspc/ndmvr-core).
- After copying the repository, you can run `npm install` to install all dependencies.
- Then, you can run `npm run dev` to start the development server.

### NPM package
- If you wish to use provided components in your own project, you can install the package using `npm install ndmvr-core`.
- Then, you can import and use the components in your project.
- Provided components are written in Three.js, so you can use them in any project that uses Three.js or any other Three.js-based framework.
- You can get inspired on how to use these components at our Gtilab demo which uses A-Frame, or you can check out our other open-source project [NdmVr](https://gitlab.com/ndmspc/ndmvr), which is built on top of React-Three-Fiber.
- Alternatively, you can head to our [tutorial](components/tutorial/tutorial.md) and see how to use the components in basic Three.js applications.
